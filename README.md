## 📌 Featured projects

### 🧪 [TestForge AI: SDET and Intelligent Test Automation Platform](https://github.com/Dileep5/testforge-ai-sdet-automation)
Playwright TypeScript test platform for a full-stack React, FastAPI and PostgreSQL order-management app, covering UI, API, contract, database, security, accessibility and k6 performance testing in a **14-job GitHub Actions pipeline with retries off**.

| Suite | Tests |
|---|---|
| API (APIRequestContext) | 154 |
| OpenAPI contract (Ajv) | 100 |
| Authorization and IDOR | 114 |
| Accessibility and keyboard (axe-core) | 148 |
| PostgreSQL integrity | 44 |
| **Playwright in Docker** | **666 passed** |

Plus a separate **650-test WebKit soak with no flaky tests**, and an AI failure-triage classifier scoring **33/36** on a held-out labelled benchmark.  
`Playwright` `TypeScript` `FastAPI` `PostgreSQL` `Ajv` `axe-core` `k6` `Docker` `GitHub Actions`

### 🤖 [Enterprise AI Research Agent](https://github.com/Dileep5/enterprise-ai-research-agent)
LangGraph agent with FastAPI and MCP interfaces that routes each question to hybrid document retrieval, text-to-SQL on PostgreSQL, or both, and returns cited answers or abstains.
- 🛡️ Guarded LLM-generated SQL with sqlglot AST validation and read-only transactions, and fixed a bypass found by a **25-statement adversarial probe**
- 📈 Top-1 retrieval accuracy **75% → 85%**, false refusals on reworded questions **70% → 20%**
- ✅ **160 automated tests** in GitHub Actions CI

`LangGraph` `FastAPI` `MCP` `PostgreSQL` `ChromaDB` `BM25` `sqlglot` `pytest`

### 🎓 [WLU Hybrid RAG Assistant](https://github.com/Dileep5/wlu-chatbot-rag) · [Live demo](https://wlu-hybrid-rag-assistant.streamlit.app)
Hybrid RAG assistant for Wilfrid Laurier University with SQL-first routing, BM25 and embedding retrieval, cross-encoder reranking and a cited source on every answer.
- 🎯 **202/202** correct on a 202-question development benchmark, declining all 22 out-of-scope questions
- 🔁 **235 automated regression checks**, with weekly data refresh through GitHub Actions

`Python` `ChromaDB` `SQLite` `BM25` `GPT-4o-mini` `Streamlit` `Docker`

### 🏗️ [Retail Data Lakehouse and Analytics Platform](https://github.com/Dileep5/retail-data-lakehouse)
Medallion pipeline from CSV and PostgreSQL into Bronze and Silver Parquet layers and a PostgreSQL warehouse, with incremental dbt models and SCD Type 2 history.
- 🧹 Great Expectations checks, **40 dbt tests**, 14 reconciliation checks per batch and **59 automated tests**
- 🔄 Verified idempotent reruns across **all 9 warehouse tables**

`PySpark` `dbt` `Apache Airflow` `Great Expectations` `PostgreSQL` `Parquet`
